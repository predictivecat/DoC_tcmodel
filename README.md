The individual power spectrums can be found in data, for Paris and Liege seperately. For Paris patient data, you need to use the index.mat to read the index of the uws, mcs, local-global, and resting-state recordings.

The codes to run the fitting and analysis and plotting can be found in fitting_code. And some plotting functions are in the distributionPlot_Width folder.

The fitting_results folder contains some of the results to generate the figures, such as the model parameters and the complexity measures for both the real recordings and simulated time series.
